# Воркшоп по git - удаление .env файла из истории коммитов

Контекст - проект, выбранный для данного кейса является клоном Яндекс Погоды, и использует внешнее погодное API для получения информации о погоде. Для использования данного апи необходим индивидуальный ключ.

Суть задачи:
- В файле `.env` закоммичен ключ к API в открытом виде
- Ключ появился там в не в последнем коммите, а примерно на середине истории коммитов
- Необходимо удалить файл из истории коммитов, добавить его в `.gitignore`, но сохранить локально, для возможности запуска проекта

## Как пользоваться

- Сделайте fork данного репозитория
- Склонируйте локально
- Решите локально
- Сравните локальную и удалённую ветку main, разница должна быть в удалении файла `.env` и добавлении файла `.gitignore`
